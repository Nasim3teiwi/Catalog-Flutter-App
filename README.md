# Catalog-Flutter-App
A Flutter mobile application for managing a simple product catalog and shop orders. Designed for sales representatives who visit stores and need a fast offline tool to browse products, add items to an order, and save orders locally. The app is fully Arabic RTL uses SQLite for local storage, and focuses on a clean and easy-to-use catalog interface.
